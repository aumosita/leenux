## 🔧 최근 주요 성과

### Load-Use Hazard 버그 수정 ✅

**문제**: 
```
lbu x12, 0(x11)     # 메모리에서 'H' (72) 읽기
beq x12, x0, end    # x12가 0으로 평가되어 잘못 분기
```

**원인**: 
- `tick()` 함수에서 stall 체크가 `fetch()`에만 있음
- `execute()`와 `decode()`가 stall 중에도 실행됨
- 결과: Load 후 1 cycle 대기하지 않고 즉시 사용

**해결**: 
```swift
// tick() 수정
if stallCycles > 0 {
    stallCycles -= 1
    // decode()와 execute() 스킵 ✅
} else if !memStalled {
    execute()
    decode()
}
```

**결과**:
```bash
$ swift run risc-emulator Examples/uart_test.bin
[UART TX: 72]
H  ✅ 성공!
```
